# M1 — omp host（纯 CLI）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建 Rust workspace：`omp-protocol`（serde 协议类型）+ `omp-host`（切帧/背压/生命周期）+ `omp-gui` CLI 入口，spawn 真实 `omp --mode rpc-ui` 跑完一轮 prompt、事件按序打到 stdout、全程无 panic。

**Architecture:** 一会话一子进程（蓝图 §3）。stdout 按 `\n` 切帧、非 JSON 旁路日志、未知事件宽容解析落 `Unknown` 分支。stdin 写入走 bounded channel（背压）。零 UI；M2 才引入 Tauri/React（规格 `docs/superpowers/specs/2026-11-01-omp-x-frontend-design.md` §0/§10）。

**Tech Stack:** Rust stable、tokio（process/sync/io-util/rt/macros/time）、serde/serde_json、thiserror、clap（derive，仅 CLI）。

## Global Constraints

- Workspace 根：`/home/wr1ench/omp-X`。本机 crates.io 直连 403，必须配 rsproxy 稀疏镜像（Task 1）。
- 帧上限 1 MiB（`maxFrameBytes=1048576`）。超限记 `Oversized` 旁路日志，不 panic。64 MiB 重装暂不实现（真实单帧从未逼近 1 MiB；需要时 M2 前加）。
- 非 JSON stdout 行（如 `[wecombot] …`）永不 panic，旁路日志。
- 未知 JSON 事件类型永不解析失败，落 `Unknown(Value)`。
- stdin 写入 bounded channel 容量 32；满时 `try_send` 错误上浮，不静默丢。
- 子进程参数（omp 路径、cwd）只来自 CLI 参数（蓝图 §7）。
- M1 不写任何 UI 代码，不建 `omp-tauri`。
- `cargo test --workspace` 全绿；涉真实 omp 的步骤标 smoke 并给期望输出。

```rust
use serde_json::Value;

#[derive(Debug, PartialEq)]
pub enum RawLine {
    Json(Value),
    Noise(String),
    Oversized { len: usize },
}

pub struct LineSplitter {
    buf: Vec<u8>,
    max_frame_bytes: usize,
}

impl LineSplitter {
    pub fn new(max_frame_bytes: usize) -> Self {
        Self { buf: Vec::new(), max_frame_bytes }
    }

    pub fn push(&mut self, chunk: &[u8]) -> Vec<RawLine> {
        let mut out = Vec::new();
        self.buf.extend_from_slice(chunk);
        loop {
            match self.buf.iter().position(|&b| b == b'\n') {
                Some(idx) => {
                    let line: Vec<u8> = self.buf.drain(..=idx).collect();
                    out.push(classify(&line[..line.len() - 1], self.max_frame_bytes));
                }
                None => {
                    if self.buf.len() > self.max_frame_bytes {
                        let len = self.buf.len();
                        self.buf.clear();
                        out.push(RawLine::Oversized { len });
                    }
                    break;
                }
            }
        }
        out
    }
}

fn classify(line: &[u8], max_frame_bytes: usize) -> RawLine {
    if line.len() > max_frame_bytes {
        return RawLine::Oversized { len: line.len() };
    }
    match serde_json::from_slice::<Value>(line) {
        Ok(v) => RawLine::Json(v),
        Err(_) => RawLine::Noise(String::from_utf8_lossy(line).into_owned()),
    }
}
```

```rust
use serde_json::{Map, Value};

#[derive(Debug, Clone)]
pub enum Inbound {
    Ready(Ready),
    Response(Response),
    ExtensionUiRequest(ExtensionUiRequest),
    Event(AgentEvent),
    Unknown(Value),
}

#[derive(Debug, Clone)]
pub struct Ready {
    pub protocol_version: u32,
    pub max_frame_bytes: u64,
}

#[derive(Debug, Clone)]
pub struct Response {
    pub command: String,
    pub success: bool,
    pub data: Option<Value>,
    pub error: Option<String>,
}

#[derive(Debug, Clone)]
pub struct ExtensionUiRequest {
    pub id: String,
    pub method: String,
    pub title: Option<String>,
    pub options: Option<Vec<String>>,
    pub extra: Map<String, Value>,
}

#[derive(Debug, Clone)]
pub enum AgentEvent {
    AgentStart(Value),
    TurnStart(Value),
    MessageStart(Value),
    MessageUpdate { event: AssistantMessageEvent },
    MessageEnd(Value),
    TurnEnd(Value),
    AgentEnd(Value),
    PromptResult(Value),
    SessionSettled(Value),
    ToolExecutionStart(Value),
    ToolExecutionEnd(Value),
    AvailableCommandsUpdate { commands: Vec<Value> },
    Raw(Value),
}

#[derive(Debug, Clone)]
pub enum AssistantMessageEvent {
    ThinkingStart(Value),
    ThinkingDelta(Value),
    ThinkingEnd(Value),
    TextStart(Value),
    TextDelta(Value),
    TextEnd(Value),
    ToolcallStart(Value),
    ToolcallDelta(Value),
    ToolcallEnd(Value),
    Raw(Value),
}

impl Inbound {
    /// 宽进解析：任何形状都不 panic，认不出的落 Unknown。
    pub fn from_value(v: Value) -> Self {
        let ty = v.get("type").and_then(Value::as_str).unwrap_or("");
        match ty {
            "ready" => Inbound::Ready(Ready {
                protocol_version: v.get("protocolVersion").and_then(Value::as_u64).unwrap_or(0) as u32,
                max_frame_bytes: v.get("maxFrameBytes").and_then(Value::as_u64).unwrap_or(0),
            }),
            "response" => Inbound::Response(Response {
                command: v.get("command").and_then(Value::as_str).unwrap_or("").to_string(),
                success: v.get("success").and_then(Value::as_bool).unwrap_or(false),
                data: v.get("data").cloned(),
                error: v.get("error").and_then(Value::as_str).map(str::to_string),
            }),
            "extension_ui_request" => {
                let mut extra = v.as_object().cloned().unwrap_or_default();
                for k in ["type", "id", "method", "title", "options"] {
                    extra.remove(k);
                }
                Inbound::ExtensionUiRequest(ExtensionUiRequest {
                    id: v.get("id").and_then(Value::as_str).unwrap_or("").to_string(),
                    method: v.get("method").and_then(Value::as_str).unwrap_or("").to_string(),
                    title: v.get("title").and_then(Value::as_str).map(str::to_string),
                    options: v.get("options").and_then(Value::as_array)
                        .map(|a| a.iter().filter_map(|o| o.as_str().map(str::to_string)).collect()),
                    extra,
                })
            }
            _ => match agent_event(&v) {
                Some(ev) => Inbound::Event(ev),
                None => Inbound::Unknown(v),
            },
        }
    }
}

/// 事件分派：蓝图 §0 实测清单。fixture 出现清单外 type → 加变体；字段形状不定 → 存 Value。
fn agent_event(v: &Value) -> Option<AgentEvent> {
    let ty = v.get("type").and_then(Value::as_str)?;
    let ev = match ty {
        "agent_start" => AgentEvent::AgentStart(v.clone()),
        "turn_start" => AgentEvent::TurnStart(v.clone()),
        "message_start" => AgentEvent::MessageStart(v.clone()),
        "message_update" => {
            let inner = v.get("assistantMessageEvent").cloned().unwrap_or(Value::Null);
            AgentEvent::MessageUpdate { event: assistant_event(inner) }
        }
        "message_end" => AgentEvent::MessageEnd(v.clone()),
        "turn_end" => AgentEvent::TurnEnd(v.clone()),
        "agent_end" => AgentEvent::AgentEnd(v.clone()),
        "prompt_result" => AgentEvent::PromptResult(v.clone()),
        "session_settled" => AgentEvent::SessionSettled(v.clone()),
        "tool_execution_start" => AgentEvent::ToolExecutionStart(v.clone()),
        "tool_execution_end" => AgentEvent::ToolExecutionEnd(v.clone()),
        "available_commands_update" => AgentEvent::AvailableCommandsUpdate {
            commands: v.get("commands").and_then(Value::as_array).cloned().unwrap_or_default(),
        },
        _ => return None,
    };
    Some(ev)
}

fn assistant_event(v: Value) -> AssistantMessageEvent {
    let ty = v.get("type").and_then(Value::as_str).unwrap_or("");
    match ty {
        "thinking_start" => AssistantMessageEvent::ThinkingStart(v),
        "thinking_delta" => AssistantMessageEvent::ThinkingDelta(v),
        "thinking_end" => AssistantMessageEvent::ThinkingEnd(v),
        "text_start" => AssistantMessageEvent::TextStart(v),
        "text_delta" => AssistantMessageEvent::TextDelta(v),
        "text_end" => AssistantMessageEvent::TextEnd(v),
        "toolcall_start" => AssistantMessageEvent::ToolcallStart(v),
        "toolcall_delta" => AssistantMessageEvent::ToolcallDelta(v),
        "toolcall_end" => AssistantMessageEvent::ToolcallEnd(v),
        _ => AssistantMessageEvent::Raw(v),
    }
}

/// 应答格式（§0）：{"type":"extension_ui_response","id":"…","value":…}
pub fn extension_ui_response(id: &str, value: Value) -> String {
    serde_json::json!({"type": "extension_ui_response", "id": id, "value": value}).to_string()
}
```

```rust
use crate::framing::{LineSplitter, RawLine};
use omp_protocol::inbound::Inbound;
use std::path::PathBuf;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio::process::Command;
use tokio::sync::{broadcast, mpsc};

pub const OUTBOUND_CAPACITY: usize = 32;

#[derive(Debug, Clone)]
pub struct SessionConfig {
    pub omp_path: PathBuf,
    pub cwd: PathBuf,
    pub extra_args: Vec<String>,
}

pub struct SessionHandle {
    pub events: broadcast::Receiver<Inbound>,
    pub noise: mpsc::Receiver<String>,
    pub outbound: mpsc::Sender<String>,
    child: tokio::process::Child,
}

impl SessionHandle {
    pub fn child_pid(&self) -> u32 {
        self.child.id().expect("child already reaped")
    }
}

impl Drop for SessionHandle {
    fn drop(&mut self) {
        let _ = self.child.start_kill();
    }
}

pub async fn spawn_session(cfg: SessionConfig) -> std::io::Result<SessionHandle> {
    let mut child = Command::new(&cfg.omp_path)
        .args(&cfg.extra_args)
        .current_dir(&cfg.cwd)
        .stdin(std::process::Stdio::piped())
        .stdout(std::process::Stdio::piped())
        .stderr(std::process::Stdio::null())
        .kill_on_drop(true)
        .spawn()?;

    let stdout = child.stdout.take().expect("piped");
    let stdin = child.stdin.take().expect("piped");

    let (events_tx, events_rx) = broadcast::channel::<Inbound>(1024);
    let (noise_tx, noise_rx) = mpsc::channel::<String>(64);
    let (outbound_tx, outbound_rx) = mpsc::channel::<String>(OUTBOUND_CAPACITY);

    // stdout 读 task：read_until 切帧（蓝图 §4.1）→ 分类 → 广播/旁路
    tokio::spawn(async move {
        let mut reader = BufReader::new(stdout);
        let mut splitter = LineSplitter::new(1_048_576);
        let mut raw = Vec::new();
        loop {
            raw.clear();
            match reader.read_until(b'\n', &mut raw).await {
                Ok(0) | Err(_) => break, // EOF 或读错：收尾
                Ok(_) => {
                    for line in splitter.push(&raw) {
                        match line {
                            RawLine::Json(v) => {
                                let _ = events_tx.send(Inbound::from_value(v));
                            }
                            RawLine::Noise(s) => {
                                let _ = noise_tx.send(s).await;
                            }
                            RawLine::Oversized { len } => {
                                let _ = noise_tx
                                    .send(format!("<oversized frame dropped: {len} bytes>"))
                                    .await;
                            }
                        }
                    }
                }
            }
        }
        // stdout 关闭 = 子进程不再输出；events_tx drop 让接收端感知
    });

    // stdin 写 task：bounded outbound → 子进程
    tokio::spawn(async move {
        let mut stdin = stdin;
        while let Some(mut line) = outbound_rx.recv().await {
            line.push('\n');
            if stdin.write_all(line.as_bytes()).await.is_err() {
                break;
            }
        }
    });

    Ok(SessionHandle { events: events_rx, noise: noise_rx, outbound: outbound_tx, child })
}
```

```rust
use anyhow::Context;
use clap::Parser;
use omp_host::session::{spawn_session, SessionConfig};
use omp_protocol::inbound::{extension_ui_response, AgentEvent, Inbound};
use std::path::PathBuf;
use tokio::io::{stdin, AsyncBufReadExt, BufReader};

#[derive(Parser)]
#[command(about = "omp GUI host (M1: headless event dump)")]
struct Args {
    /// omp 可执行文件路径
    #[arg(long, default_value = "omp")]
    omp_path: PathBuf,
    /// 会话工作目录
    #[arg(long)]
    dir: PathBuf,
    /// 发送的一轮 prompt；缺省则只连不发（观察 ready/commands 推送后退出）
    #[arg(long)]
    prompt: Option<String>,
    /// 透传给 omp 的额外参数（如 --approval-mode=always-ask）
    #[arg(long = "extra-arg", value_name = "ARG")]
    extra_args: Vec<String>,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let args = Args::parse();
    let cfg = SessionConfig {
        omp_path: args.omp_path.clone(),
        cwd: args.dir.clone(),
        extra_args: args.extra_args.clone(),
    };
    let mut h = spawn_session(cfg)
        .await
        .with_context(|| format!("spawn {}", args.omp_path.display()))?;

    if let Some(prompt) = &args.prompt {
        let cmd = serde_json::json!({
            "type": "command", "command": "send_prompt", "prompt": prompt
        });
        h.outbound
            .send(cmd.to_string())
            .await
            .context("outbound channel closed")?;
    }

    // stdin 后台泵：用户在终端输入一行即作为下一轮 prompt 发送（M1 调试用）
    {
        let outbound = h.outbound.clone();
        tokio::spawn(async move {
            let mut lines = BufReader::new(stdin()).lines();
            while let Ok(Some(line)) = lines.next_line().await {
                if line.trim().is_empty() {
                    continue;
                }
                let cmd = serde_json::json!({
                    "type": "command", "command": "send_prompt", "prompt": line
                });
                if outbound.send(cmd.to_string()).await.is_err() {
                    break;
                }
            }
        });
    }

    loop {
        tokio::select! {
            ev = h.events.recv() => {
                match ev {
                    Ok(Inbound::Event(AgentEvent::SessionSettled(v))) => {
                        println!("session_settled {v}");
                        break;
                    }
                    Ok(Inbound::ExtensionUiRequest(req)) => {
                        // M1 无人 UI：select/confirm 一律 Deny（安全默认，§7）；其余方法丢弃但打印
                        println!(
                            "ui_request id={} method={} title={:?} -> auto-Deny",
                            req.id, req.method, req.title
                        );
                        if matches!(req.method.as_str(), "select" | "confirm") {
                            let resp = if req.method == "select" {
                                extension_ui_response(&req.id, serde_json::json!("Deny"))
                            } else {
                                extension_ui_response(&req.id, serde_json::json!(false))
                            };
                            let _ = h.outbound.send(resp).await;
                        }
                    }
                    Ok(Inbound::Unknown(v)) => println!("unknown {v}"),
                    Ok(ev) => println!("{ev:?}"),
                    Err(tokio::sync::broadcast::error::RecvError::Lagged(n)) => {
                        eprintln!("warn: lagged {n} events");
                    }
                    Err(tokio::sync::broadcast::error::RecvError::Closed) => break,
                }
            }
            noise = h.noise.recv() => {
                if let Some(line) = noise {
                    println!("noise {line}");
                }
            }
        }
    }
    Ok(())
}
```
